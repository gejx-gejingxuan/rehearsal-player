# 剧本排练播放器（网页版）

为剧本/英语剧排练制作的网页播放器：**单文件、无后端、纯 HTML5 原生播放**，白色主题与桌面版一致。

## 使用

1. 打开 [在线版](https://gejx-gejingxuan.github.io/yingyuju-player/) 或把 `index.html` 下载到本地双击打开
2. 点「添加视频」或把 mp4 文件 / 文件夹拖进页面
3. 底栏彩色数字卡片即片段列表，点击或按数字键切换

## 快捷键

| 按键 | 功能 |
| --- | --- |
| 1-9 / 0 | 切换到第 1-9 / 第 10 个片段（自动播放） |
| 空格 | 播放 / 暂停 |
| F / 双击画面 | 全屏（隐藏底栏） |
| G | 半全屏（保留底栏） |
| Esc | 退出全屏 |
| ← / → | 快退 / 快进 5 秒 |
| ↑ / ↓ / 滚轮 | 音量加减 |
| M | 静音 |
| A / B / X | 设 A 点 / 设 B 点 / 清除 AB（配合「AB 截取」循环） |
| L / N | 单段循环 / 自动连播 |

## 说明

- 浏览器安全限制：视频不会上传到任何服务器，全部在本机播放；关闭页面后列表不保留，下次打开需重新选择文件
- 支持 mp4 / m4v / mov / webm / mkv 等浏览器可解码的格式
