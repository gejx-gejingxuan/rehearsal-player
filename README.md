# Rehearsal Player（剧本排练播放器 · 网页版）

为剧本/英语剧排练制作的网页播放器：**单文件、无后端、纯 HTML5 原生播放**，白色主题与桌面版一致。Rehearsal Player is a single-file, zero-backend rehearsal player.

## 使用

1. 打开 [在线版](https://gejx-gejingxuan.github.io/rehearsal-player/) 或把 `index.html` 下载到本地双击打开
2. 点「添加视频 / 图片」或把文件 / 文件夹拖进页面
3. 底栏彩色数字卡片即片段列表，点击或按数字键切换
4. 支持图片（jpg / png / gif / webp）：与视频混排，连播模式下每张自动停留 5 秒
5. 选中片段后，下方编辑栏可单独设置：名称、音量、速度，或上移 / 下移 / 删除
6. 「保存 ZIP」把全部片段 + 设置 + **播放顺序**打包下载（含 config.json），「导入 ZIP」按原顺序完整恢复（导入会替换当前列表）
7. ⚙ 设置：可开关「画面中央暂停图标」（设置自动记忆）

## 编码兼容（老系统黑屏）

若视频是 **H.265 / HEVC** 编码，Windows 7（以及未装 HEVC 扩展的 Windows）浏览器无法解码，会**有声音、无画面**。

- 页面会自动识别：这类片段的卡片显示 `H.265 · 需转码`
- 顶栏出现「转码」按钮，点一下把全部不兼容片段转成 H.264（在浏览器内完成，不上传、不需安装任何软件）
- 首次使用需联网下载约 32MB 转码组件，之后走缓存；21 分钟素材约需 8-10 分钟
- 转码结果可直接用「保存 ZIP」导出，拷到老电脑上「导入 ZIP」即用

## 快捷键

| 按键 | 功能 |
| --- | --- |
| 1-9 / 0 | 切换片段（自动播放） |
| 空格 | 播放 / 暂停 |
| F / 双击画面 | 全屏 |
| Esc | 退出全屏 |
| Alt+左键 / Alt+右键 | 上一个 / 下一个片段 |
| ◀ / ▶ 按钮 | 上一个 / 下一个片段 |
| ← / → | 快退 / 快进 5 秒 |
| ↑ / ↓ / 滚轮 | 音量加减 |
| M | 静音 |
| A / B / X | 设 A 点 / 设 B 点 / 清除 AB（配合「AB 截取」循环） |
| L / N | 单段循环 / 自动连播 |
| 保存 ZIP / 导入 ZIP | 打包 / 恢复全部片段与设置 |

## 说明

- 浏览器安全限制：视频不会上传到任何服务器，全部在本机播放；关闭页面后列表不保留，下次打开需重新选择文件
- 支持 mp4 / m4v / mov / webm / mkv 等视频与 jpg / png / gif / webp 图片混排播放
